# RikkyoTimeSheetPy

立教大学及び立教大学大学院でRAをしていると避けられないのが，出勤簿入力．かなり面倒な作業である．
本成果物は，RAの出勤簿入力を楽に効率化するために作られたものです．

# 使い方

V-campus idとパスワード，勤務内容を入力後に，使いたいウェブドライバを選択すると，自動で勤怠管理画面までもっていってくれます．
```Ctrl```キーで**勤務内容入力**，```s```キーで**始業時刻**，```e```キーで**終業時刻**，```b```キーで**休憩開始時刻**，```f```キーで**休憩開始時刻**を自動入力します．

# これから実装したいこと

アルバイト区分の自動選択

# 注意

```v1.py```は旧勤怠管理サイトに対応しているものなので，それを使っても意味はないです．
